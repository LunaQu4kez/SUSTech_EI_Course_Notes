2D FOURIER TRANSFORM ANALYSIS - AMPLITUDE AND PHASE SPECTRA
============================================================

This directory contains visualizations of 2D Fourier transforms.

KEY FILES:
1. amplitude_phase_<domain>.png - Main visualization of amplitude and phase
2. complete_analysis_<domain>.png - Complete analysis including original image
3. amplitude_<domain>_<image>.png - Individual amplitude spectrum
4. phase_<domain>_<image>.png - Individual phase spectrum
5. spectra_comparison_summary.png - Cross-domain comparison

INTERPRETATION:
- Amplitude spectrum shows frequency strength
- Phase spectrum shows frequency phase angles
- Center of images = low frequencies
- Edges of images = high frequencies
